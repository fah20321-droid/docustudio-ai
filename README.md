# DocuStudio AI

نسخة أولية عربية من DocuStudio AI لإدارة مشاريع الفيديو والسيناريو والمشاهد والترجمات.

## التشغيل محلياً
يتطلب Python 3.10 أو أحدث.

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

ثم افتح: http://127.0.0.1:8000

## ملاحظة
هذه نسخة تأسيسية قابلة للتطوير. توليد الصور/الفيديو بالذكاء الاصطناعي غير مفعّل تلقائياً؛ يحتاج إلى ربط مزود API ومفاتيح خاصة.
